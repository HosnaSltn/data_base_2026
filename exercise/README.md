# Course Exercise

This directory contains the course exercises and guides to the tools required to complete them.

## Exercises

The exercises are provided in separate files, each covering a different part of the course material.

## Tools

The `Tools/` directory contains the following guides:

1. [Basic LaTeX Guide](<Tools/LaTeX.md>)  — Covers the essential LaTeX syntax and commands needed to prepare exercise solutions.
    
2. [Visual Paradigm Guide](<Tools/Visual Paradigm.md>)  — Explains the features and workflows of Visual Paradigm required to complete the database modeling exercises.
    

## Usage

Review the exercise files and refer to the guides in the `Tools/` directory to learn the LaTeX and Visual Paradigm features needed to complete the exercises.
