## Reference Textbooks

The following textbooks serve as supplementary references for the course.

1. [An Introduction to Database Systems](<An Introduction to Database Systems.pdf>)  
   **Author:** C. J. Date  
   **Edition:** 8th, 2003

2. [Database Management Systems](<Database Management Systems.pdf>)  
   **Authors:** Raghu Ramakrishnan and Johannes Gehrke  
   **Edition:** 3rd, 2002

3. [Database System: A Practical Approach to Design, Implementation, and Management](<Database System A Practical Approach to Design Implementation and Management.pdf>)  
   **Authors:** Thomas Connolly and Carolyn Begg  
   **Edition:** 6th, 2014

4. [Database System Concepts](<Database System Concepts.pdf>)  
   **Authors:** Abraham Silberschatz, Henry F. Korth, and S. Sudarshan  
   **Edition:** 7th, 2020

5. [Fundamentals of Database Systems](<Fundamentals of Database Systems.pdf>)  
   **Author:** Ramez Elmasri  
   **Edition:** 7th, 2015

## Usage

The professor's slides are the primary lecture materials. The textbooks can be used as supplementary references for reviewing concepts, exploring additional examples, and developing a deeper understanding of database systems.
